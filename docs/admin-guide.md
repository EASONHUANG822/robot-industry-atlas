# 管理员操作指南

## 访问后台

1. 打开 `https://你的域名/zh/admin`（本地开发：`http://localhost:3000/zh/admin`）
2. 使用管理员账号登录

## 账号

| 项目 | 值 |
|------|-----|
| 用户名 | 由 `ADMIN_USERNAME` 环境变量设置 |
| 密码 | 由 `ADMIN_PASSWORD` 环境变量设置 |
| 会话有效期 | 8 小时（httpOnly Cookie） |

## 功能一：日期管理（Date Management）

登录后默认进入日期管理页。功能基于飞书多维表格，数据存储在你配置的 `LARK_BITABLE_TABLE_ID_BLOCKED_DATES` 表中。

### 界面说明

| 区域 | 说明 |
|------|------|
| 统计卡片 | 顶部三张卡片：已屏蔽日期数 / 已约满日期数 / 部分预约日期数 |
| 月历 | 可左右翻月，每天的圆角方块用颜色标注状态 |

### 颜色含义

| 颜色 | 状态 | 含义 |
|------|------|------|
| 绿色 | 可预约 | 当天无人预约，完全空闲 |
| 黄色 | 部分预约 | 有人预约但未达到上限 |
| 红色 | 已约满 | 达到每日上限（默认 4 人） |
| 深灰色 | 已屏蔽 | 管理员手动屏蔽，前台不可选 |
| 浅灰色 | 已过期 | 今天之前的日期，不可操作 |

### 操作方式

- **屏蔽日期**：点击未来的日期方块，该日期变为深灰色。前台预约日历中该日期即刻不可选。
- **取消屏蔽**：再次点击已屏蔽的日期，恢复为正常状态。
- **已约满/部分预约日期**：同样可以手动屏蔽，效果同上。

> 屏蔽操作实时生效，数据写入飞书多维表格。无需重启。

### 屏蔽 vs 约满的区别

- **约满**：由系统自动计算，当某日期 `Status = "Done"` 的申请数 ≥ 4 时自动标记
- **屏蔽**：管理员手动设置，优先级高于约满状态。比如某天只有 1 个预约但你不想再接，可以直接点击屏蔽

前台的预订日历对这两种状态一视同仁——都显示为不可选。

## 功能二：反馈管理（Feedback）

点击顶部 **Feedback** 标签进入。

### 状态标签

| 标签 | 内容 |
|------|------|
| All | 全部反馈 |
| Pending | 待审核的反馈 |
| Approved | 已通过，会展示在前台页面 |
| Rejected | 已拒绝，不对外展示 |

### 操作按钮

| 按钮 | 适用状态 | 效果 |
|------|----------|------|
| Approve | Pending | 审核通过，前台可见 |
| Reject | Pending | 拒绝展示 |
| Edit | Pending / Approved | 修改反馈文字 |
| Feature | Approved | 标记为精选，前台高亮展示 |
| Unfeature | Approved（已精选） | 取消精选 |
| Delete | Approved / Rejected | 永久删除 |
| Restore | Rejected | 恢复到 Pending 状态 |

## 数据存储说明

| 数据 | 存储位置 |
|------|----------|
| 参观申请 | Airtable（`AIRTABLE_TABLE_NAME`）+ 飞书多维表格同步 |
| 用户反馈 | Airtable（`AIRTABLE_FEEDBACK_TABLE_NAME`）+ 飞书多维表格同步 |
| 屏蔽日期 | 飞书多维表格（`LARK_BITABLE_TABLE_ID_BLOCKED_DATES`） |

### 飞书屏蔽日期表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| Date | 文本 | 日期，格式 `YYYY-MM-DD`，例如 `2026-07-15` |

表创建在飞书多维表格 app `JHxnwP8DciEvKukoEyFcHWO5nLe` 下。

## 每日预约上限

系统默认每个日期最多允许 **4** 个 `Status = "Done"` 的申请。达到 4 个后该日期自动变为约满。

如需修改，编辑 `src/server/airtableApplications.ts` 中的常量：

```ts
const MAX_DONE_APPLICATIONS_PER_VISIT_DATE = 4;
```

## 故障排查

### 日期管理页加载失败（502 / 红色报错）

1. 确认飞书应用权限中已开启 `bitable:app`
2. 确认 `LARK_BITABLE_TABLE_ID_BLOCKED_DATES` 环境变量配置正确
3. 确认飞书多维表格 app 下存在对应的表，且表中有 `Date` 文本字段

### 点击日期没有反应

1. 打开浏览器开发者工具（F12）→ Network 标签
2. 点击日期，查看 `/api/admin/blocked-dates` 请求的响应
3. 红色报错信息会显示具体原因

### 前台日历未更新

屏蔽操作即时生效，但前台页面需要刷新或重新打开 BookingCalendar 才会重新请求数据。
